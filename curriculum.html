A practical path from curiosity to portfolio projects. Schools and colleges can adopt a full track or pick modules that fit their calendar and kits.

Three pillars

Every track balances AI concepts, robotics builds, and IoT sensing — so students see how software meets the physical world.

Learning style

Short theory → guided lab → mini-project. Assessment is demos and a final showcase, not only written tests.

Flexible delivery

Modules map to our School, College, Online and Onsite packages. Duration can be compressed into intensives.

Foundation

Ages ~11–15 · Schools

Build confidence with sensors, simple code and “what AI can / cannot do.” Ideal for middle and early secondary.

Module 1 · Digital & AI literacy

  • What is data, a model, and a prediction?
  • Everyday AI (maps, voice, photo filters)
  • Safe and fair use of AI tools
  • Activity: train a simple image classifier (block-based or guided)

Module 2 · First robots

  • Motors, wheels, power and safety
  • Line-follower or obstacle-avoider build
  • Basic control loops (if sensor → action)
  • Team roles: builder, tester, presenter

Module 3 · Sensors & IoT intro

  • Temperature, light, ultrasonic, buttons
  • Read a value → show it on screen or LED
  • Idea of “device talks to computer”
  • Mini project: classroom environment monitor

Capstone · Show & tell

  • One team project combining sensor + motion or display
  • 2-minute demo + what they would improve next
  • Certificate of participation

Outcomes: students can explain AI simply, assemble a basic robot, and read/display a sensor value.

Intermediate

Ages ~15–18 · Secondary / early college

Deeper code, structured projects, and portfolio pieces suitable for college applications or competitions.

Module 1 · Applied AI

  • Classification vs regression (intuition + tiny datasets)
  • Train/test split and “why models fail”
  • Intro to computer vision demos (e.g. object detection showcase)
  • Prompting LLMs responsibly for learning support

Module 2 · Robotics systems

  • Chassis design, sensors placement, tuning
  • State machines for robot behavior
  • Optional: simple mapping or path following
  • Debug checklist and log habits

Module 3 · IoT projects

  • Microcontroller + multiple sensors
  • Log data to serial / simple dashboard
  • Threshold alerts (e.g. plant moisture, room noise)
  • Networking basics (when kit supports Wi‑Fi)

Capstone · Portfolio project

  • Problem statement → prototype → demo video
  • GitHub or shared folder with photos/code notes
  • Peer review and teacher feedback form

Outcomes: a documented project, comfort with kits, and clear vocabulary for AI / robotics / IoT interviews.

Advanced

College / academy · ages 18+

Closer to industry practice: pipelines, evaluation, and integration — still hands-on, not pure theory.

Module 1 · ML & vision pipelines

  • Dataset hygiene and simple annotation practices
  • Train a small model; measure accuracy / errors
  • YOLO or similar detection demo on real images
  • Ethics: bias, privacy, deployment limits

Module 2 · Chatbots & RAG intro

  • Grounded answers vs generic chat
  • Retrieve from documents → answer with sources
  • Use case: campus FAQ or course assistant prototype
  • Reference: open projects like Edu RAG

Module 3 · Edge, IoT & automation

  • Sensor → gateway → dashboard flow
  • Lightweight inference on constrained devices (concepts + demos)
  • Automation scripts for data collection
  • Reliability: retries, power, field conditions

Capstone · Team product sprint

  • 1–2 week scoped product (vision, bot, or IoT)
  • Roles: data, firmware/hardware, software, presentation
  • Showcase for faculty / parents / local partners

Outcomes: portfolio-ready system, teamwork under constraints, and readiness for internships or freelance starter projects.

Suggested weekly rhythm (example)

2–3 hours / week: 20–30 min concept → 60–90 min lab → 15 min reflection.
Intensive (5–7 days): same modules compressed with longer daily builds.
