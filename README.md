- Static HTML / CSS / JS + Three.js
- Blog with Article + FAQ schema (JSON-LD)
- robots.txt + sitemap.xml
- Hosted on GitHub Pages

## Enable GitHub Pages

Repo → **Settings** → **Pages** → Source: **Deploy from a branch** → `main` / `/ (root)`.

Then submit in Google Search Console:
`https://zuhaibbutt786.github.io/deepvidia/sitemap.xml`
